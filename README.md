# MusIF
# Gestão de Instrumentos Musicais

Protótipo de um sistema web desenvolvido como Projeto Integrador, com o objetivo de auxiliar na organização e no gerenciamento dos instrumentos musicais do Instituto Federal (IF).

## Objetivo

Centralizar as informações dos instrumentos musicais e facilitar o acompanhamento de empréstimos, devoluções e outras informações relevantes para a gestão do acervo.

## Funcionalidades previstas

- Cadastro e consulta de instrumentos musicais.
- Registro e acompanhamento de empréstimos.
- Controle de devoluções.
- Consulta da disponibilidade dos instrumentos.
- Organização do histórico de movimentações do acervo.

## Status do projeto

Em fase inicial de planejamento e desenvolvimento.

## Equipe

Projeto desenvolvido em dupla como atividade acadêmica do Projeto Integrador.
